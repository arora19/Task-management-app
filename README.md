Task Management APP
code files: __init__.py, models.py, resources.py, routes.py, run.py
Uses Flask for the web framework.
Sqlite for the database queries.
RESTful APIs.
flask shell to make data entries into database tables or curl commands to make API calls.
CRUD opeartions to manage data in tables.

Create single/multiple users each with their own identifier. Each user can create their own tasks and sort them by their priority status. Have the ability to manage data entries in the database with ease.
